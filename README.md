# CityMETER: Luxury Brands Thailand

**Live demo: [montri-th.github.io/luxurybrands](https://montri-th.github.io/luxurybrands/)** · [Source repository](https://github.com/montri-th/luxurybrands)

ถ้าจะเปิดร้านที่นี่ จะอยู่ข้างใคร: เห็นก่อนว่าแบรนด์ luxury, upscale streetwear, Thai designers และ curated retailers กระจุกอยู่ย่านใดในประเทศไทย ในภาพเมือง 3 มิติที่โฟกัส 3 ย่านอันดับต้นทันที แล้วเจาะลงถึงศูนย์การค้า อาคาร และหมุดรายสาขาพร้อมหลักฐานรายรายการ รุ่น 0.3 (22 ต.ค. 2569) เพิ่ม basemap กระดาษที่สร้างเอง มวลอาคารทั้งเมืองแบบเงียบ อาคารมุมโค้งในย่านโฟกัส กล้องแบบโมเดลเมือง/มุมสถาปนิก breadcrumb ที่เข้ากับ CityMETER production และ Product Statement แบบ winning strategy · รุ่น 0.4 (22 ต.ค. 2569) อาคารของสถานที่มองเห็นและกดได้เสมอ (venue x-ray) กรอบจังหวัดพร้อม drill-down เมื่อดูทั้งประเทศ และ pictogram บน metric tiles · รุ่น 0.5 (22 ต.ค. 2569) โลโก้สถานที่ในแผง รายการ และรายละเอียดร้าน จากทะเบียน venue logos ของชีต research

**Research snapshot: 21 Oct 2026 · Record grain: brand–point of sale · Artifact status: public research demo, not production.**

ฐานรวบรวมใหม่มี **349 สาขา** และเก็บประวัติต้นฉบับของมายด์ **352 แถว** ไว้ตรวจสอบย้อนกลับ เว็บไซต์รวม **565 research records** ซึ่งมีทั้งรายการใหม่และข้อสังเกตประวัติ ไม่ใช่ 565 ร้านที่เปิดอยู่ การจับคู่ประวัติกับรายการใหม่ไม่ทำให้เป็นสาขาเพิ่มอีกหนึ่งแห่ง

ผลตรวจ snapshot นี้: รายการใหม่มีพิกัด **349/349** แถว แบ่งเป็นจุดสถานที่จากแหล่งข้อมูล **171** แถว และจุดตัวแทนศูนย์/อาคาร **178** แถว; ประวัติเดิมใช้พิกัดได้ **348/352** แถว อีก **4** แถวพักพิกัดเพื่อตรวจตัวตน พบข้อสังเกตปิดถาวร **21** แถว และปิดชั่วคราว **1** แถว ค่าเริ่มต้นแสดง **345** รายการใหม่ โดยพัก **4** รายการที่ official listing กับหลักฐานปิดขัดกันไว้จาก presence จนกว่าจะตรวจเพิ่ม ตัวเลขเหล่านี้ซ้อนขอบเขตกันและไม่ควรบวกเป็นจำนวนร้านทั้งหมด

อ่าน metadata ล่าสุดจาก [data/luxury.json](data/luxury.json) และจำนวนตามตัวกรองบนหน้าจอ การมีพิกัดครบไม่เท่ากับยืนยันประตูร้านหรือการเปิดจริงจากภาคสนาม

## ใช้งาน

```sh
npm start
```

เปิด <http://127.0.0.1:4173> เพื่อพัฒนาในเครื่อง; เปิดไฟล์ index.html โดยตรงจะนำไปยังเว็บสาธารณะด้านบน แผนที่โหลดภายหลังข้อมูล โดยมีสถานะและปุ่มลองใหม่เมื่อล้มเหลว; ไม่ต้อง build หรือติดตั้ง dependencies ภายในโปรเจกต์ (Node ≥ 20 สำหรับ tests/scripts, Python 3 สำหรับ server) แผนที่ใช้เครือข่ายเพื่อโหลด MapLibre GL 5.6.2 และ OpenFreeMap vector tiles ส่วนกราฟวาดด้วย HTML/SVG ภายในโปรเจกต์ ไม่มีไลบรารีกราฟ

```sh
npm test
```

ชุดทดสอบ 81 ข้อตรวจสถานะ หน่วยนับ หมุดรายสาขาแม้ใช้พิกัดเดียวกัน การแยกหมุดบนหน้าจอ ขอบเขตย่าน การกรองร่วม สเกลสี `count` และ class thresholds โปรไฟล์ย่าน/สถานที่/ร้าน สถานะ EVID-05 ของย่าน ตัวอ่าน vector tile เรขาคณิต offset/มุมโค้ง มวลอาคาร โครง basemap ที่สร้างเอง กล้อง breadcrumb และรหัสจังหวัด ส่วนความอ่านง่ายและพฤติกรรมแผนที่กับกราฟตรวจในเบราว์เซอร์แยกต่างหาก (ดู `handoff/VERIFICATION.md`) สคริปต์ `npm run handoff:manifest`, `npm run handoff:bundle` และ `npm run verify:live` สร้าง manifest/bundle และเทียบ hash กับไฟล์บนเว็บจริง

## สิ่งที่สำรวจได้

- **3D ก่อน ย่านก่อน:** หน้าแรกเปิดเป็นเมือง 3 มิติ (pitch 56°) ที่โฟกัส 3 ย่านอันดับต้นโดยอัตโนมัติ แผงอ่านข้อมูลเปิดด้วยสัดส่วนแบรนด์ที่อยู่ใน 3 ย่านนั้น พร้อมอันดับย่านทั้งหมด และแผนที่ระบายสีย่านตามแบรนด์ไม่ซ้ำด้วย LDS `count` family (5 ระดับเท่าช่วง ประกาศในคำอธิบาย HEX เดียวกันทั้งสองธีม) ซูมเข้าเกิน 14.5 สีจะสลับเป็นเส้นขอบเพื่อให้หมุดและอาคารเป็นพระเอก ปุ่ม “ดูทุกย่าน” ยกเลิกโฟกัสอัตโนมัติ (`?areas=all`) ปุ่ม “3D” สลับเป็นแผนผัง 2 มิติ
- **focus + quiet:** เฉพาะย่านที่โฟกัสมีสี หมุดสีประเภท โลโก้ อาคารที่ตั้ง และมวลอาคารมุมโค้ง ส่วนอื่นเหลือเส้นขอบบาง ป้ายจาง จุดบริบทสีเทาเล็ก ๆ ที่ยังคง “1 จุด = 1 รายการ” และมวลอาคารเมืองโทนเงียบ
- **มวลอาคารสองชั้น:** อาคารทั้งเมืองจาก OpenStreetMap ผ่าน OpenFreeMap tiles เป็นบริบทเงียบ อาคารในย่านโฟกัสถูกถอดจาก tile เดียวกัน ขยายออกเล็กน้อยแล้วลบมุมโค้ง (คำตอบเชิงแสดงผลต่อ maplibre-style-spec #1047 ที่ MapLibre ยังไม่รองรับ) เป็นโมเดลเมืองแบบ simplified ความสูงเป็นบริบทจาก OSM ไม่ใช่ข้อมูลของชุดนี้
- **กล้อง:** ภาพรวมใช้มุมเมือง ย่านใช้มุมโมเดล (FOV 14° เส้นตั้งตั้งตรงใกล้ axonometric) และระดับสถานที่ใช้ “มุมสถาปนิก” — เปอร์สเปกทีฟ 2 จุด (pitch 75 / FOV 24) ที่จัดกรอบพอดีอาคารของสถานที่ อาคารรอบข้างจางลงมาก และอาคารที่บังสถานที่โปร่งใส (ปิดได้ด้วยปุ่มเดียวกัน)
- **ระดับสถานที่:** เมื่อเปิดศูนย์การค้า เฉพาะอาคารของศูนย์นั้นเป็นสีน้ำเงินและเฉพาะร้านในศูนย์นั้นมีหมุดสีประเภท/โลโก้ อาคารและร้านของศูนย์อื่นถอยเป็นบริบทเงียบ
- **breadcrumb:** ประเทศไทย › จังหวัด › ย่าน › สถานที่ ด้วยรหัสจังหวัดเดียวกับ CityMETER production (BKK, CMI, …) และ Shopping Center id ของ CityMETER เป็น id ของสถานที่ URL ใช้ `?province=BKK&neighborhood=siam&place=<id>` สถานที่นอกย่านทั้ง 10 ข้ามระดับย่าน
- **โปรไฟล์ย่าน:** อันดับ ตัวเลข บุคลิกตามกลุ่มแบรนด์ สถานที่ในย่าน แบรนด์เฉพาะย่าน / แบรนด์ที่พบในย่านอื่นด้วย (เทียบทุกย่านในตัวกรอง ไม่ใช่เฉพาะย่านที่เลือก) และขอบเขตที่ใช้พร้อมแหล่งอ้างอิง
- **สถานที่และร้าน:** ศูนย์การค้า/ทำเลพร้อม GLA ที่รายงานและสาขา; ร้านพร้อมโลโก้ สถานะจริง รูปแบบ พิกัดและระดับความแม่น (จุดร้านจากแหล่งทางการ / ผู้ให้บริการแผนที่ / จุดตัวแทนอาคาร) วันที่ตรวจ หลักฐาน และสาขาอื่นของแบรนด์
- หนึ่งหมุดต่อหนึ่งสาขา ไม่มีการรวมหมุด; หมุดที่ใช้พิกัดร่วมกันแยกใกล้ต้นทางบนจอ; เส้นชี้ต้นทางเฉพาะหมุดที่เลือกหรือชี้; โลโก้สูงสุด 250 จุด เฉพาะ zoom ≥ 14 และเฉพาะส่วนที่ focus โดยให้แบรนด์ต่างกันมีโอกาสแสดงก่อน
- อาคารที่ตั้งใช้ footprint/parts จากแหล่งข้อมูลจริง สี `map.activeLayer` ของ LDS พร้อมแยกความสูงที่ทราบจากแผ่นแสดงรูปทรง 3 เมตรเมื่อไม่ทราบความสูง
- กราฟสามมุมมอง (อันดับย่าน · ตารางตัวเลขย่าน × กลุ่มแบรนด์ที่ทุกช่องขนาดเท่ากัน · แบรนด์เฉพาะ/ร่วม) วาดด้วย HTML/SVG ทุกแท่งและช่องเป็นปุ่มจริง ใช้คีย์บอร์ดได้ และใช้สีระดับเดียวกับแผนที่
- ตัวกรองยุบใน disclosure พร้อมชิปตัวกรองที่ใช้อยู่; URL เก็บตัวกรอง จังหวัด (รหัส) ย่าน สถานที่ ร้าน โฟกัส มุมมองกราฟ โหมด 2D/3D และมุมสถาปนิก
- รายการเดิมที่ยังยืนยันใหม่ไม่ได้ และร้านที่มีหลักฐาน `permanently closed` โดยไม่ลบประวัติ; missing ไม่แสดงเป็น 0

โครงสร้างหน้าจอยึด [CityMETER Shopping Center production](https://landometer.com/v3/citymeter?d=shoppingCenter) และ `CmMapLayout.tsx`: header 48 px แผนที่เต็ม viewport ที่เหลือ แผงขวา `min(max(300px, 28%), 440px)` และถาดกราฟซ้อนด้านล่างที่ย่อได้ (52 px) ค่าเริ่มต้นย่อกราฟเพื่อเปิดพื้นที่แผนที่ จอมือถือแนวตั้งใช้ bottom sheet ไม่เกิน 64dvh พร้อม Aha ย่อบนแผนที่เมื่อแผงปิด; แนวนอนใช้แผงขวา 42%

ขอบเขตตั้งต้นมี 10 ย่าน: สยาม ราชประสงค์ ชิดลม–เพลินจิต พร้อมพงษ์ ทองหล่อ ทรงวาด อารีย์–อารีย์สัมพันธ์ นิมมาน เจริญนคร และสีลม มี 244/345 รายการค่าเริ่มต้นอยู่ในขอบเขต อีก 101 รายการยังอยู่ภายนอกและแสดงต่อไป ไม่บังคับจับเข้าย่านใกล้ที่สุด รายละเอียดช่วงขอบที่ยังเป็นการตีความอยู่ใน method; ชื่อย่านที่มีหลักฐานไม่ได้พิสูจน์ว่าคนทั่วไปยอมรับเส้นขอบนี้ร่วมกัน

basemap ทั้งสองธีมสร้างเองใน `js/map-style.js` บน [OpenFreeMap](https://openfreemap.org/) vector tiles (OpenMapTiles schema, ข้อมูล OpenStreetMap) ด้วยสี `--basemap-*` ใน `assets/theme.css` แทน style สำเร็จรูป Positron/Dark ของรุ่นก่อน: ถนนขาว พื้นที่สีเขียวจาง มวลอาคารเทา-ขาว ไม่มี POI ป้ายใช้ `name:th` ก่อน และท้องฟ้า/หมอกทำให้ระยะไกลจางลง โดยคง attribution ของ OpenFreeMap, OpenMapTiles และ OpenStreetMap

กราฟไม่ใช้ไลบรารีภายนอกตั้งแต่รุ่น 0.2: `js/charts.js` วาดแท่ง ตารางตัวเลข และแท่งซ้อนจาก `js/chart-model.js` โดยตรง ดูนิยามและการตรวจใน [docs/CHART_SELECTION.md](docs/CHART_SELECTION.md)

## Assets and verification

ใช้ LDS **0.9.7 / v0.9.7-owner.1** (standalone-0.9.7-r1, color-srgb-10) พร้อม fonts และเฉพาะค่าที่หน้านี้ใช้จริง: foundation pairs, semantic states, map roles, data states, categorical series 1–10 ใน [assets/theme.css](assets/theme.css) และ LUT 41 ค่าของ `count` family ใน [js/scales.js](js/scales.js) (ไม่แนบคลัง LDS ทั้งชุด) ไฟล์ asset บันทึก byte length และ SHA-256 ใน [assets/manifest.json](assets/manifest.json) และทุกไฟล์ของ repository บันทึกใน [handoff/handoff-manifest.json](handoff/handoff-manifest.json) ผลตรวจ hash ไม่ใช่การรับรองว่า demo ผ่านการตรวจ UI หรือ production แล้ว ต้องรายงานผลหน้าจอจริงแยกจาก hash checks (ดู `handoff/VERIFICATION.md`)

คง attribution ของ OpenFreeMap/OpenMapTiles/OpenStreetMap ตามสิทธิ์ผู้ให้บริการ ไม่ได้รวมสิทธิ์ redistributable สำหรับข้อมูลหรือสื่อทุกอย่างของแบรนด์ ไฟล์นี้เป็น research/demo snapshot และยังต้องจัดทำกระบวนการอัปเดต สิทธิ์ข้อมูล และ field validation ก่อนยกระดับเป็น production dataset

ทะเบียนโลโก้มี 168 อัตลักษณ์จากแหล่งทางการ 155 และ retailer 13 ครอบคลุมทุกชื่อแบรนด์ใน research records ชุดนี้ โดยไม่นับจำนวนโลโก้เป็นจำนวนร้าน ใช้ไฟล์ภายในเว็บ คงรูปทรง สี และสัดส่วนต้นฉบับ ตัดเฉพาะพื้นที่ว่างภายนอกเพื่อให้อ่านได้ในพื้นที่เล็ก และรักษาไฟล์ต้นทางตาม SHA-256 ดู [brand logo manifest](assets/brand-logos-manifest.json) และ [catalog](data/brand-logos.json) เครื่องหมายยังเป็นของเจ้าของแบรนด์ การแสดงเพื่อระบุตัวตนใน demo ไม่สื่อถึงการรับรองหรือสิทธิ์ใช้งานทั่วไป
