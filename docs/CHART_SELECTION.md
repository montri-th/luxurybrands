# กราฟเปรียบเทียบย่าน

คัดเลือกจากตัวอย่างทางการของ amCharts 5 เมื่อ 2026-10-21 และปรับให้ใช้ข้อมูลที่เลือกใน CityMETER จริง ใช้ runtime 5.20.8 (`index.js` + `xy.js`) ไม่มีข้อมูลตัวอย่างหรือค่าจำลองปะปน

| มุมมอง / key | คำถามที่ตอบ | ตัวอย่างต้นแบบ | การอ่านและการเลือก |
| --- | --- | --- | --- |
| แบรนด์ในแต่ละย่าน / `centers` | ย่านใดมีแบรนด์ไม่ซ้ำมากที่สุดในข้อมูลที่เลือก? | [Bar Chart](https://www.amcharts.com/demos/bar-chart/) | แท่งเริ่มที่ 0 ความยาวแทนแบรนด์ไม่ซ้ำ ปลายแท่งแสดงจำนวน คลิกเพื่อดูย่าน |

ใช้วิธีวาง category axes, circle bullets และ stacked series จากตัวอย่างข้างต้น แต่ไม่ใช้ animation, live random updates หรือสีตัวอย่าง การแสดงผลใช้ Bai Jamjuree, ตัวเลข JetBrains Mono และ categorical tokens เดิมของ LDS 0.9.7 ตามธีม ไม่มี gradient หรือการแปลงสีข้อมูลเอง

## ความหมายของจำนวน

`js/chart-model.js` รับ selected rows หลังตัวกรองจากแอป และใช้ `summarizeNeighborhoods` / `assignNeighborhood` จาก `js/neighborhoods.js` เป็นเจ้าของการจัดพื้นที่ จุดหนึ่งอยู่ได้หนึ่งย่านตาม polygon และ priority ที่ตรึงไว้ ชื่อย่านในข้อความไม่ทำให้จุดถูกย้ายย่าน

- **แบรนด์ไม่ซ้ำ:** Set ของชื่อแบรนด์ในแต่ละขอบเขต จุดขายหลายรายการของแบรนด์เดียวกันไม่เพิ่มจำนวนแบรนด์
- **รายการจุดขาย:** จำนวน observation rows ตาม grain ของ dataset ไม่เปลี่ยนเป็นจำนวนร้านจากการรวมตำแหน่ง
- **เฉพาะย่านนี้:** พบแบรนด์ในย่านที่กำหนดหนึ่งย่าน ภายใน selected rows เท่านั้น
- **พบในย่านอื่นด้วย:** พบแบรนด์เดียวกันอย่างน้อยสองย่านที่กำหนด ภายใน selected rows
- **ขอบเขตการเทียบ:** คำนวณกับทุกย่านที่มีจุดขายใน selected rows ก่อนตัดอันดับที่แสดง จึงไม่เรียกแบรนด์ว่าเฉพาะเพราะอีกย่านตกนอก top N
- จุดนอก polygon ไม่ถูกเดาว่าอยู่ย่านใด และยังคงอยู่ใน `totalPos` / `totalBrands`; กราฟนับเฉพาะจุดที่จัดลงย่านได้

คำว่าเฉพาะไม่ใช่ข้อสรุปว่าแบรนด์มีแห่งเดียวในประเทศไทย และไม่ยืนยันผลธุรกิจ ยอดขาย อุปสงค์ หรือความครบถ้วนของตลาด แบรนด์เดียวที่มีหลาย segment นับครั้งเดียวต่อช่อง แต่ไม่ควรรวมทุกช่องเป็นจำนวนแบรนด์รวม

## รูปแบบในแผงขนาดเล็ก

จำนวนแถวขึ้นกับความสูงจริง ส่วน matrix เลือกกลุ่มตามจำนวนแบรนด์รวมแบบไม่ซ้ำในย่านที่แสดง แล้วจำกัดคอลัมน์ตามความกว้าง แสดง `จำนวนที่เห็น/จำนวนทั้งหมด` ในกราฟเพื่อให้ขอบเขตชัด คำย่อบนแกนมีชื่อเต็มและค่าตัวเลขใน tooltip เลข 0 หมายถึงไม่มี observation ที่เลือกในช่องนั้น ไม่ใช่หลักฐานว่าไม่มีร้านจริง

รัศมีวงกลมเป็น `sqrt(count / maxCount) × maxRadius` เพื่อให้ **พื้นที่** แปรตามจำนวนโดยมีจุดอ้างอิงศูนย์ ไม่ยืดขนาดวงเล็กด้วย minimum radius ตัวเลขที่อ่านได้จะแสดงในวงใหญ่ และทุกวงมีค่าแน่นอนผ่าน tooltip / aria label

เมื่อเทียบได้ไม่ถึงสองย่าน แสดง “เลือกอย่างน้อย 2 ย่านเพื่อเปรียบเทียบ” กับปุ่ม “ดูทุกย่าน” แทนการเรียกทุกแบรนด์ว่าเฉพาะย่าน กรณีไม่มีข้อมูลหรือ library โหลดไม่ได้มีทางไปดูแผนที่/ตาราง การ dispose root ป้องกัน canvas และ event ซ้ำ ทุกกราฟหยุด animation รวมถึงเมื่อใช้ reduced motion

## Integration contract

`renderInsightChart({elementId, view, rows, centers, segments, neighborhoods, theme}, onSelect)` คืน idempotent disposer; `centers` ยังคงรับได้เพื่อความเข้ากันได้ แต่ geometry ใน `neighborhoods` เป็นผู้กำหนด membership ทุก mark ส่ง `{type:'neighborhood', id}`; ปุ่ม reset ส่ง `{type:'resetAreas'}` และแอปเป็นผู้รักษาตัวกรองอื่น

## การตรวจ

`tests/chart-model.test.js` ตรวจค่าจริงเริ่มต้น 345 observations / 113 แบรนด์, 10 ย่านที่มีข้อมูล, 244 rows ในขอบเขต และ 101 rows นอกขอบเขต; อันดับต้นคือสยาม 57 แบรนด์ / 64 rows, พร้อมพงษ์ 51 / 56 และชิดลม–เพลินจิต 45 / 55 ตรวจ duplicate POS, union/overlap ก่อนตัดอันดับ, ทุก cell รวม zero, ขอบเขตหลังกรอง, ไม่มี textual reassignment, nonmutation และสัดส่วนพื้นที่วงกลม

ผล unit tests แยกจากการตรวจภาพจริง ความอ่านง่าย คลิก และแป้นพิมพ์ที่ viewport/ธีมจริง รายงาน UI QA ตามที่ตรวจได้ ไม่อ้าง browser pass จาก model tests
