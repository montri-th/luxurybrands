# ขอบเขตย่านที่ใช้ใน Luxury Brands

ขอบเขตในแผนที่เป็น **แกนย่านเชิงวิเคราะห์ที่มีชื่อและเส้นตัดตรวจย้อนกลับได้** ใช้รวมร้านภายในพื้นที่เดียวกันอย่างสม่ำเสมอ เลือกเส้นถนน คลอง และริมแม่น้ำจากแผนที่ OpenStreetMap แล้วลดรายละเอียดเส้น ไม่มีรัศมี วงกลม convex hull หรือการต่อร้านใกล้กันเป็นลูกโซ่ ร้านนอกขอบเขตคงสถานะยังไม่จัดเข้าย่าน

ชื่อย่านมีหลักฐานจากผู้ดูแลพื้นที่ เจ้าของสถานที่ องค์กรท่องเที่ยว และคู่มือสถานที่ แต่ **การมีชื่อย่านที่ใช้ทั่วไปไม่ได้พิสูจน์ว่าทุกคนเห็นตรงกันเรื่องเส้นแบ่ง** เส้นตัดที่เลือกเป็นการตีความของผู้วิเคราะห์ ไม่ใช่เขตปกครอง ขอบเขตสิทธิบริการ หรือผลสำรวจการรับรู้ของผู้บริโภค พื้นที่รอยต่อที่ยังมีข้อสงสัยแสดงสถานะ candidate

`desk-reviewed` หมายถึงตรวจความสอดคล้องชื่อ จุดอ้างอิง และเส้นแผนที่บนโต๊ะแล้ว ไม่หมายถึงผ่านการรับรองโดยชุมชน ส่วน `candidate` ยังต้องทบทวนเส้นตัดหรือรอยต่อกับพื้นที่ข้างเคียง ค่า confidence แสดงความมั่นใจในเส้นที่วาด แยกจาก nameConfidence ภายในไฟล์ข้อมูล

ทรงวาดใช้ส่วนแกนร้านฝั่งตะวันตกของถนนทรงสวัสดิ์ จึงไม่ครอบคลุมถนนทรงวาดทั้งหมดถึงข้าวหลาม และไม่รวมเยาวราชหรือตลาดน้อยทั้งย่าน นิมมานเลือกห้วยแก้วเป็นขอบเหนือ แม้ [MAYA เรียกที่ตั้งแยกรินคำว่าพื้นที่นิมมาน](https://mayashoppingcenter.com/en/about-us/) แต่บล็อกเหนือถนนยังอยู่นอก core นี้ ต้องตรวจขอบถนน/แปลงเพิ่มก่อนขยาย ไม่ขยับขอบเพื่อให้ร้านที่คาดไว้เข้าพื้นที่

ข้อมูลชุดนี้ยังไม่มีขอบเขตย่านครบประเทศไทย กลุ่มร้านในศูนย์การค้าเดียวที่ภูเก็ต พัทยา เมืองอื่น และสนามบินยังใช้มุมมองศูนย์การค้า/สถานที่ได้ การยังไม่จัดเข้าย่านไม่ได้แปลว่าไม่มีชื่อย่านหรือไม่มีตลาด

เจริญนครใช้แกนริมแม่น้ำรอบ ICONSIAM ที่ปิดด้วยถนนและคลองจริง ไม่เท่ากับถนนเจริญนครทั้งหมด จุดตัดสี่มุมคำนวณจากเส้นต้นทาง สีลมปิดด้วยถนนสุรวงศ์–พระราม4–สาทรเหนือ–นราธิวาสราชนครินทร์ โดยต่อจุดปลายช่องจราจรเฉพาะภายในทางแยกจริง สวนลุมพินีและ One Bangkok อยู่อีกฝั่งพระราม4 และยังไม่รวมเข้าย่านนี้

## การรวมร้าน

ใช้ point-in-polygon กับขอบเขตที่บันทึกคงที่ก่อนกรองแบรนด์/ประเภท/จังหวัด ตัวกรองเปลี่ยนจำนวนและรายการร้าน แต่ไม่สร้างหรือเลื่อนขอบเขตใหม่ ไม่ใช้คอลัมน์ชื่อย่านเดิมตัดสินสมาชิก จุดบนขอบนับรวม หากอยู่บนขอบร่วมกันเลือก priority ที่น้อยกว่า ตามด้วยรหัสย่านเพื่อให้ผลแน่นอนเสมอ

จุดร้านบางรายการเป็นจุดแทนศูนย์การค้าหรืออาคารเจ้าบ้าน ตำแหน่งสมาชิกจึงรับข้อจำกัดนั้นด้วย จำนวนจุดขายไม่เท่ากับจำนวนอาคาร และจำนวนแบรนด์เป็นแบรนด์ไม่ซ้ำในข้อมูลที่ผ่านตัวกรอง ไม่มีการประมาณยอดขายหรือพฤติกรรมลูกค้าจากขอบเขต

## หลักฐานและการตรวจต่อ

ไฟล์ [neighborhoods.geojson](../data/neighborhoods.geojson) เก็บ definition, edges, status, checkedOn, confidence และ sourceURLs รายย่าน แยกแหล่งยืนยันชื่อ (`identitySourceURLs`) จากเส้นแผนที่ (`geometrySourceURLs`) วันที่ตรวจไม่ใช่วันสำรวจภาคสนาม และจำนวนทศนิยมไม่ใช่ค่าความแม่นยำ

- [PMCU](https://pmcu.co.th/contact/) ยืนยันสยามสแควร์และที่ตั้งหลัก ส่วนขอบรอบกลุ่มสยามที่ใช้ถนนและคลองเป็นการเลือกของผู้วิเคราะห์
- [Ratchaprasong District](https://bkkdowntown.com/) ให้บริบทกลุ่มร้านและผู้ประกอบการราชประสงค์ เส้นใต้และตะวันออกที่เลือกยังเป็น candidate
- [Central Embassy](https://www.centralembassy.com/directory/central-embassy-bk/level-1/) ยืนยันที่ตั้งมุมวิทยุ–เพลินจิตและความเชื่อมโยง Central Chidlom
- [EM District](https://emdistrict.com/tourist/) ยืนยันสามศูนย์การค้ารอบสถานีพร้อมพงษ์ ส่วนขอบนอกใช้ถนนที่ระบุไว้ ไม่ถือคำว่า “official area” ในคู่มือการอยู่อาศัยเป็นอำนาจทางปกครอง
- [MICHELIN Guide ฉบับกรกฎาคม2026](https://guide.michelin.com/th/en/article/travel/song-wat-bangkok-neighborhood-guide) ให้บริบททรงวาดริมแม่น้ำและแยกอัตลักษณ์จากตลาดน้อย
- [Airbnb × TBAA 2018–2019 หน้า5](https://news.airbnb.com/wp-content/uploads/sites/4/2018/09/Airbnb-x-TBAA-Thailand-Neighbourhood-Guide-EN.pdf) อธิบายอารีย์ระหว่างพหลโยธินและพระราม6 ใช้เป็นหลักฐานชื่อและบริบท ไม่ใช่หลักฐานร้านยังเปิดในปี2026
- [Time Out](https://www.timeout.com/bangkok/things-to-do/things-to-do-in-thonglor) ให้บริบทเครือข่ายซอยรอบสุขุมวิท55
- [การท่องเที่ยวแห่งประเทศไทย](https://www.thailandtravel.or.jp/nimmanhaemin-street/) ให้บริบทถนนนิมมานในเชียงใหม่
- [ICONSIAM HALL](https://www.iconsiamhall.com/en/plan-your-visit) ยืนยันการเข้าถึงสถานที่ด้วยถนนเจริญนคร สถานีเจริญนคร และทางเรือ
- [Dusit Residences](https://dusitresidences.com/location/) ยืนยันที่ตั้งหัวมุมสีลม–พระราม4 และความเชื่อมโยงกับศาลาแดง ประกอบกับ [Dusit Thani Bangkok](https://www.dusit.com/dusitthani-bangkok/th/experience/central-park-shopping-mall/)

เส้นถนน/คลอง/ริมแม่น้ำอ่านจาก OpenStreetMap API ในวันที่ตรวจ และระบุ way URLs ที่เกี่ยวข้องในแต่ละ feature บางจุดเป็นการตัดและเชื่อมเส้นที่ลดรายละเอียด ไม่ใช่แนวเขตที่ดิน แสดงเครดิต **© OpenStreetMap contributors** และ [ODbL 1.0](https://www.openstreetmap.org/copyright) เมื่อเผยแพร่ชั้นข้อมูลนี้
