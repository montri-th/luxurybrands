วิธีใช้

    
  

  
หน้าแรกคือเมือง 3 มิติที่โฟกัส 3 ย่านที่มีแบรนด์มากที่สุด — เลือกย่าน แล้วเจาะลงถึงศูนย์การค้าและสาขา

  
    
    
  1. ข้อค้นพบแรก
    แผงขวาบอกว่าแบรนด์กระจุกอยู่ย่านใด แผนที่โฟกัสย่านเหล่านั้นให้แล้ว · “ดูทุกย่าน” เปิดทุกย่านเท่ากัน
    2. 
    
  2. เส้นทาง
    ประเทศไทย › จังหวัด › ย่าน › สถานที่ — กดระดับใดก็ได้เพื่อย้อนกลับ
    3. 
    
  3. สีย่านและกรอบจังหวัด
    สีเข้ม = แบรนด์มาก (ช่วงตัวเลขอยู่ในคำอธิบายมุมล่างซ้าย) ย่านนอกโฟกัสเหลือเส้นขอบ · เมื่อซูมออกทั้งประเทศ จังหวัดที่มีแบรนด์จะมีกรอบและป้าย กดเพื่อเจาะลงจังหวัด
    4. 
    
  4. อาคาร
    สีน้ำเงิน = อาคารของสถานที่ที่เปิดอยู่ มองเห็นเสมอแม้มีอาคารอื่นบัง และกดได้ · เทาเข้ม = อาคารในย่านโฟกัส · อาคารอื่นจางลงตามระยะ · “3D” สลับเป็นแผนผัง · “มุมสถาปนิก” คือมุมมองระดับสถานที่ที่อาคารรอบข้างโปร่งใส
    5. 
    
  5. หมุด
    1 หมุด = 1 สาขา สีหมุด = กลุ่มแบรนด์ (ดู “สีประเภทแบรนด์”) กดหมุดเพื่อดูสถานะและหลักฐาน · โลโก้สถานที่ในแผงช่วยจำศูนย์การค้า ชื่อสถานที่ยังเป็นตัวระบุหลัก
    6. 
    
  6. กราฟและตาราง
    “เปิดกราฟ” เทียบย่าน (อันดับ · กลุ่มแบรนด์ · เฉพาะ/ร่วม) · “รายการ” เปิดตารางสาขา
    7.
